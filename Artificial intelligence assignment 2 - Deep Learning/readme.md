# Deep Learning Foundations

## Overview
This assignment contains computational implementations of foundational deep learning concepts, bridging theoretical mathematics and practical code. It explores model architecture, error quantification, and iterative optimization techniques.

## Modules

### Chapter 2: Supervised Learning
Parametric models and foundational 1D linear regression.

### Chapter 3: Shallow Neural Networks
1D and 2D network formulations, topological computation of maximum linear regions, and experimentation with non-linear mapping functions (ReLU, Sigmoid, Tanh).

### Chapter 5: Loss Functions
Maximum likelihood estimation, least squares, and negative log-likelihood applications for both binary and multiclass classification.

### Chapter 6: Optimization Algorithms
Foundational 1D and multidimensional loss minimization, mini-batch stochastic optimization, learning rate scheduling, and advanced convergence techniques using standard/Nesterov momentum and Adaptive Moment Estimation (Adam).

## Lessons Learned
* **Architecture Construction:** Successfully translated mathematical primitives into functional neural network architectures from scratch.
* **Activation Impact:** Demonstrated how different non-linear activation functions drastically alter the representational capacity and the resulting linear regions of a network.
* **Loss Function Selection:** Gained practical insight into the mechanics of coordinate descent and why cross-entropy provides a more navigable loss landscape than least squares for classification tasks.
* **Optimization Dynamics:** Observed firsthand how advanced optimizers like Momentum and Adam accelerate convergence, handle noisy gradients, and navigate saddle points significantly better than standard gradient descent.
